# REASONABLE TECH

Reasonable Tech is a startup-style workspace scaffold with a React frontend and an Express API backend.

## Stack

- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express

## Getting started

1. Install dependencies:
   npm install
2. Start both services:
   npm run dev
3. Open the app in the browser at:
   http://localhost:5173/
4. API health check:
   http://localhost:3001/api/health

## Project structure

- frontend/ — Vite React application
- backend/ — Express API server
- .github/copilot-instructions.md — workspace guidance

## Useful scripts

- npm run dev — run backend and frontend together
- npm run build — build the frontend production bundle
- npm run start:backend — run the backend without watch mode
- npm run preview:frontend — preview the static frontend build
